今日智慧心小提醒 (Wise Mind)

「感受是真實的，但感受並不總是事實。」當情緒湧上時，試著暫停 3 秒，問問你的智慧心：現在最有效的行動是什麼？

DBT 四大核心技巧領域

1. 了了分明技巧 (Mindfulness)

「是什麼」與「如何做」了了分明覺察

2. 痛苦承受 (Distress Tolerance)

危機處置，不讓情況變得更糟

3. 情緒調節 (Emotion Regulation)

理解情緒、核對事實、相反行動

4. 人際效能 (Interpersonal)

表達需求(DEAR MAN)、維護關係(GIVE)、自尊(FAST)與認可

SOS 危機速效平靜指引

當前情緒極度高漲時（困擾值 > 7），請勿強求思考邏輯，先透過身體生理機制進行調節：

T Temperature (改變體溫)

用冷水洗臉，或用冰敷袋敷在眼眶下方 30 秒。這能迅速啟動「哺乳類潛水反射」，降低心率與交感神經興奮。

Google Sites 內嵌說明

為什麼無法在獨立新頁面開啟？

因為您目前是直接將 HTML 程式碼貼在 Google Sites 的「內嵌程式碼」中，Google 並未為此 HTML 檔案提供獨立的 Web 網址，因此瀏覽器基於安全性會禁止開啟沙盒新分頁。

💡 建議的兩種最佳使用方式：

  1. 直接使用全螢幕功能：點擊 APP 右上角「全螢幕按鈕」即可放大畫面操作。
  2. 免費獲得獨立網址：將此 `index.html` 檔案免費上傳至 GitHub Pages 或 Vercel，再將產生的專屬網址貼入 Google Sites，即可完美實現跨裝置 100% 獨立新頁面開啟與持久儲存！
